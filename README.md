# knowledge_rag

A small, end-to-end Retrieval-Augmented Generation (RAG) pipeline: drop documents into `knowledge/`,
build an index, and chat with them. Answers are grounded in your files and cite their sources.

```
Index time   python ingest.py   loaders -> chunking -> embeddings -> vector_store (+ manifest)
Query time   python chat.py     chat_engine -> retriever (dense + BM25 -> RRF) -> prompts -> llm
```

## Quick start

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows   (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt

copy config.example.yaml config.yaml   # macOS/Linux: cp ...  then add your API key
python check_setup.py             # preflight: config, packages, providers, index
python ingest.py                  # build the index (incremental on later runs)
python chat.py                    # interactive chat
```

Other commands:

| Command | What it does |
|---|---|
| `python chat.py --ask "question"` | answer one question and exit |
| `python chat.py --search "question"` | show retrieved passages only (no LLM call) |
| `python chat.py --verbose` | also show rewritten query, timings, retrieval scores |
| `python ingest.py --rebuild` | re-embed everything (needed after changing the embedding model) |
| `python evaluate.py [--k 3] [--with-llm]` | Recall@k / MRR on `eval/questions.jsonl`, optional answer check |
| `python check_setup.py --list-models` | list the models your key (or local Ollama) can serve |
| `python -m unittest discover -s tests -t .` | run the test suite (offline, no API keys) |

Inside the chat: `/sources  /reset  /verbose  /config  /help  /exit`.

## Providers

Chat (`llm.provider`): `openai`, `anthropic`, `gemini`, `grok`, `ollama`.
Embeddings (`embeddings.provider`): `openai`, `gemini`, `ollama`, `local` (sentence-transformers), `builtin` (offline, tests only).

Keys go in `config.yaml` under `providers.<name>.api_key`, as a `${ENV_VAR}` reference, or are read from
`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `XAI_API_KEY`. `config.yaml` is git-ignored.

## Layout

```
knowledge_rag/
├── chat.py  ingest.py  evaluate.py  check_setup.py
├── config.example.yaml  config.yaml  requirements.txt  .gitignore
├── eval/questions.jsonl
├── knowledge/            your documents (.txt .md .pdf .docx .csv .html .json)
├── index/                generated by ingest.py (chunks.jsonl, vectors.npy, manifest.json)
├── rag/                  the pipeline, one stage per module
│   ├── config.py  loaders.py  chunking.py  embeddings.py  vector_store.py
│   ├── bm25.py  retriever.py  prompts.py  llm.py  chat_engine.py  pipeline.py
│   └── utils.py  errors.py
└── tests/                unit + integration tests with a fake LLM and the builtin embedder
```
